# Multiplayer Test for H3lix Protoc0l (2d Platformer Game)

Adding a second player to an existing 2d platformer of my creation in the Godot game engine.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Download Godot 4.6 or latest version
2. Copy repo to Github Desktop
3. Open Godot press import and navigate files to the repo locally, and select the project.Godot file
4. Open the project in Godot
5. Press near the top right-hand side 
   

Instructions for using the software:

1. After Starting the project navigate teh main menu, either pressing play or pressing level select and choosing a level 
2. While in a level control player 1 by either using an Game controller like an xbox, playstation, nintendo pro controller ect... or use keyboard controls (All listed below) for player 2 only keyboard controls exist for now (listed below)
3. Play and have fun

Player 1:
  Keyboard;
    Move Right: [D]
    Move Left: [A]
    Jump: [W],[Space]
    Dash: [Left Shift]
    Attack: [Q]
    Interact: [E]
    
  Xbox Controller;
    Move Right & Left: [Left Joystick]
    Jump: [A]
    Dash: [Left Trigger], [B]
    Attack: [X]
    Interact: [Y]

  Playstation
    Move Right & Left: [Left Joystick]
    Jump: [X]
    Dash: [Left Trigger], [O]
    Attack: [Square]
    Interact: [Triangle]
    
  Nintendo Pro Controler
    Move Right & Left: [Left Joystick]
    Jump: [B]
    Dash: [Left Trigger], [A]
    Attack: [Y]
    Interact: [X]

Player 2 (Keyboard Only)
    Move Right: [Right Arrow]
    Move Left: [Left Arrow]
    Jump: [Up Arrow]
    Dash: [Right Shift]
    Attack: [/]
    Interact: [']
